Patches
=======

These are scripts and files that are needed to change the server in a way to fix, update and or upgrade aspects (mostly functional parts) of the portal service. 

The changes should be done in the patch and not yet in a setup, otherwise we cannot test the patch. 

When the patch has been applied to all servers, we should make sure that the changes are also in there after the setup. Only then can we test for new changes, because the dev environment resembles the production again.
